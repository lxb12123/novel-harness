# 2026-08-14：右栏由 LLM 无感生成，作者只看和改

> **这是维护者的决策记录，不是工程约束。** 要变成约束得落进 `docs/` 或开 ADR
> （CLAUDE.md 的规矩）。**但它已经在改代码了**——见文末「今天照它做的第一刀」。

## 规则原文（作者，2026-08-14）

> 右边那栏里边的东西由 llm 在相应的时期去进行**无感生成**，生成后用户可以明确看到内容，
> 并且用户可以**手动去修改增加**之类的，然后这些值调用时候就可以取出来用。
> 那你现在很多东西，都是需要靠用户手动抽取之类的，**这个太烂了**。

## 拆成四条可验收的

右栏那九格（花名册 / 认知矩阵 / 状态 / 约束 / 局部图 / 证据 / 章节总结 / 检查 / 待确认）
**每一格**都要同时满足：

1. **谁在什么时刻生成它？** —— LLM，在恰当时机，**不由作者点按钮触发**。
2. **作者在哪儿看得见？** —— 明确显示，不是藏在库里的隐式状态。
3. **他怎么改？** —— 手工路径存在，但它是**改**和**增补**，不是**从零建**。
4. **谁取用它？** —— 写作上下文 / 规则 / 面板。

**三个问题答不上就是没做完**，哪怕代码、测试、界面都齐了。

### 死亡：2026-08-14 补上了

抽取器加了 `kind="death"`（`extract/models.py`）。**模型在一个封闭枚举里挑一个**，
`EdgeProps.value_key = HealthValue.DEAD` 仍由引擎写死成常量 —— 语义判断留在模型
那一侧，引擎这一侧仍然只做集合判断（铁律 2 没破）。

端到端钉在 `tests/test_extractor_feeds_r3.py`：模型说「他死了」→ `nh check` 在后面
的章报出「死人说话」，中间任何一层都不断言。撤掉那一档，R3 一条都不报（实测过）。

`nh declare dead` 留着当**改**的入口 —— 符合本规则第 3 条。

### 首现章：这条规则够不着它，不是待办

`first_appears_chapter` 的主要用法是「幽泉窟我打算第 200 章才让它出场」，R2 靠它
逮住提前写出的名字。**那是作者的计划，物理上不在已写文本里** —— ADR 0004 的原话是
「墙上那把枪是不是伏笔，取决于他第 200 章打不打算开枪」。

**模型读不出还没写下来的意图。** 所以这一格只能是作者填的，它不是本规则的例外，
是本规则的适用边界：**规则说的是「文本里有的东西不该让作者重抄一遍」**，
而计划本来就不在文本里。

（今天它连浏览器入口都没有 —— `POST /nodes` 有这个字段，但 2026-08-13 维护者裁定
工作台上不许出现章号输入框，`test_canon_edit_boundary` 有零基线守卫。这是另一个
待裁的问题，不是这条规则的。）
