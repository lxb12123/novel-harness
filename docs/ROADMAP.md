# 设计文档与路线图

> 本文收纳了 README 移出的设计文档索引、路线图与未来规划，面向想了解项目走向的读者。
> **系统当前状态的权威副本**在 [ARCHITECTURE.md 的「当前状态」](ARCHITECTURE.md#当前状态)，本文不抄数字。

## 项目定位

- **目标用户**：写中文长篇、正文用 Markdown、会开终端的作者；只用 WPS 且不想碰命令行的作者暂缓。
- **核心主张**：记「主观认知图」的写作引擎——谁知道、谁不知道、谁信着错的，可查询、可强制执行；AI 起草时同一份认知边界进 prompt。
- **两条铁律**：只做集合判断、不做语义判断（零误报）；时态过滤全系统只允许在 `graph/queries.py` 实现一次。

## 规划中的方向

- **AI 起草全量验证**：M2 评估已通过（维护者裁定），真模型全量运行待做。
- **真书验收**：切章数 = 目录数等验收条目仍未全部验完，等一本真实中文小说 TXT。
- **向量检索（v1.1）**：按 [ADR 0002](adr/0002-no-vector-retrieval-in-v1.md) 的触发条件制决定是否引入。
- **桌面包**：[`start.command`](../start.command) 是过渡形态；真正的 .dmg 桌面包等 M2 全量运行出结果、且有真实用户在用。
- **`--local-only` 开关**：一个显式的「彻底关掉联网」开关，尚未实现。
