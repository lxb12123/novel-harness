# EVAL_PROTOCOL 退役说明 —— 这门考试的**对象**下线了，卷子原样留着

> 2026-08-24。**这不是第十份修正案。** 修正案改的是「怎么读这份卷子」；
> 这一份说的是「卷子要考的那个东西已经不在了」。
>
> **`EVAL_PROTOCOL.md` 第 45 行起的冻结正文一个字节未改**，与 `0393088` 仍然逐字节相同。
> 九份修正案也一个字节未改。**它们保留为历史，不删、不涂改、不追加裁定。**

## 发生了什么

2026-08-24，维护者裁定**秘密这一整套功能下线**（见 ADR 0039）。

`EVAL_PROTOCOL.md` 押的那个可证伪命题是：

> 「你提前告诉 AI『这个角色现在还不该知道 X』，AI 就不会写漏」——
> 把约束图注入 Writer 的 prompt，到底能不能**降低泄漏率**。

三臂的全部差别就在这件事上：X0 零图谱事实、X1 注入认知矩阵要点、X2 同一份矩阵换散文渲染。
**秘密下线之后没有矩阵，也就没有 X1 和 X2** —— 不是「这门考试变难了」，是**它的题目不存在了**。

## 守卫改成钉什么

`tests/test_protocol_preregistration.py` 从前钉两件事：**正文未变**、
以及「九份修正案」这句话在几处当前文档里的字样一致。

现在钉三件：

1. **正文未变**（不动，这一条是这份协议存在的全部意义）；
2. **九份修正案全在**，一份不少；
3. **这份退役说明存在，且当前文档指得到它** —— 否则下一个人会读到一份看起来还能跑的卷子，
   然后去找那个已经不存在的 `synth/ground_truth.json`。

**「正文未变」和「已退役」是两个独立断言，不许合并。** 合并之后「有人偷偷改了正文」
和「有人偷偷把退役说明删了」会长成同一条红，而这两件事的下一步动作完全不同。

## 想把这门考试拿回来的话

**这份说明不构成「解冻」。** 秘密真要加回来（ADR 0039 写了触发条件），
**必须重新写一份预注册**，因为下面这些今天已经没有了：

- `synth/` 那本小册子里的秘密与 tell 集合（每条秘密配一个生造专名）；
- `synth/ground_truth.json` 的泄漏 ground truth；
- `eval/` 整个判分链（`leak` / `score` / `confound_lint` / `runner`）与 `gate.py`。

**照旧的规矩仍然适用：先把及格线提交进 git，再跑第一次推理。**
拿这份旧协议改一改充当新卷子 = 看到过结果再定及格线，那正是它当年要防的事。
