## 一、整件事在干嘛：一场「防泄漏」考试

项目押的宝是一句话：

> 「你提前告诉 AI『这个角色现在还不该知道 X』，AI 就不会写漏。」

听上去很神，但**到今天为止没人真正验证过这句话**。这场考试就是来验证它的——
而且规矩是：**在跑任何实验之前**，先把「怎么验、几分算过、几分算不过」白纸黑字写死、提交进 git。

为什么要先写死再跑？因为人都会"看菜下饭"：先看了结果再划及格线，想让它过就把线放低、想砍就抬高——那等于**先改卷子再定谁及格**。所以最大的规矩是：**及格线先提交，时间戳在先，之后每一次模型生成都必须晚于这条 commit；结果出来只能认，不能事后挪。**

这就是科学里的"预注册"，也是本项目"先证伪、再造"哲学的落地（PLAN §7 / ADR 0005）。

## 二、考什么（被证伪的命题）

> 把引擎算出来的「谁不该知道什么」（`must_not_reveal` / `forbidden_entities`，见 `panel/constraints.py`）
> 注入到写稿 prompt 时，草稿在**产品相关的 KNOWS 维度**上的泄漏率，是不是**显著低于**不注入时——
> 而且要低到「值得把 AI 起草当产品功能上线」。

如果考出来不成立（注入了也不降、或降幅小到没意义）：**砍掉 AI 起草这条线**，产品退回"纯作者的记忆外挂"（面板 + 声明 + R4），那几条不依赖模型听话，不需要这场考试。

## 三、三臂：X0 / X1 / X2 到底是什么

很多人以为三臂是三套 prompt 构造器。不是——它们是**同一个生产渲染器**（`draft/assemble.py::assemble(..., form=)`）的三个档位：

- **X0（对照组）**：不注入"不该知道"清单；
- **X1**：注入清单；
- **X2**：注入清单，再在 prompt 里多给一次"名称来源"的提示。

为什么要三臂？因为只比"注入 vs 不注入"不够——得把「下降是不是真的来自约束本身」和「下降是不是只来自写法技巧（echo）」分开。**gate 和产品共用这一份渲染代码**，不然 gate 考的是一个产品永远不会发的句式，考了等于白考。

## 四、泄漏怎么算：确定性集合判断，不猜语义

这是铁律（ADR 0005）。泄漏**不是**「让模型判断这句话是不是剧透」，而是**集合判断**：
- 泄漏 = 草稿里出现了某个**不该出现的专名/tell**（tell 集合是提前生造的、唯一的专名，不会被自然撞上）。
- 判分器**不许自己另立一份禁忌集**；禁忌集只有一个来源（`panel.constraints` 出来的 `secret_surfaces`）。
- 锚定是 `(para_index, quote_text, occurrence_k)` 三元组，**禁止 offset**。

一句话：只数"该出现的没出现 / 不该出现的出现了"，不搞语义理解。

## 五、卷子：合成小册子（`synth/build.py`）

真书太贵、太不可控，所以考试用的是一本**合成小册子**：
- 作者在 `synth/booklet.toml` 里填一份剧本（谁、在哪章、该知道什么秘密），`build.py` 自动派生 ground truth。
- 这本小册子**强制说话人标签、强制唯一 tell** —— 它测的是"注入机制通不通"，**不是真书行为**（所以拿 M2 的成绩去冒充"真书验收"是作弊，协议 §7 里已把这条免责一并写死）。

> 类比：这是"在实验室里考配方能不能防漏"，不是"直接拿你的真书去赌"。

## 六、打分与裁决（`eval/score.py`）

- 三臂各按预注册的统计口径算**泄漏率**，n 和数字都来自冻结的正文（`n=25`；X1/X2 有一定量的 KNOWS + FUTURE）。
- 判分按 `§6 裁决表` **从上到下按序判**：命中最上面那行就出那一档，PASS / KILL / INCONCLUSIVE 都算"一次有效实验"；
  只有 **INVALID** 是"仪器坏了"（卷子造错 / 判分链断了），这一轮白跑，不算证据。
- **正则化题外话**（别被吓到）：条款里那些"地板门 / 天花板门 / Δ 平票"都是在回答"这轮到底算不算数、算哪个数"——它们是维护者对抗性排除歧义用的，作者一辈子碰不到。

## 七、谁跑它、要花什么

- **作者永远不碰它**；敲它的是维护者（现在入口是 `uv run python -m novel_harness.gate`——
  2026-08-20 之前是 `nh gate`，命令行面删掉时只有它被保下来，见 ADR 0034）。
- **会真调模型、真花钱**：一轮约 225 个 final cell（成功轮因长度续写还会翻到两倍）。别手贱连着跑。
- 跑完落 `runs/<时间戳>.jsonl`，裁决写进 ADR 0009——**不在协议里写结果，也不写进 ADR 0005**。

## 记住四句就够

1. **这场考试只回答一个问题**：把"谁不该知道什么"喂给写稿 AI，泄漏率到底降不降、值不值得上线。
2. **及格线先提交、先冻结**，跑完只能认，不能挪。
3. **判分是数数（集合判断），不是理解语义**；卷子是合成的，测的是机制不是真书。
4. **会花钱，维护者专用**；PASS / KILL / INCONCLUSIVE 都是有效结论，INVALID 才是仪器坏了。
