# EVAL_PROTOCOL 修正案 7：起草功能先行开放（实验状态）

- 状态：已接受（维护者裁定 2026-08-02）
- 前置：修正案 1–6 全部早于任何 `runs/*.jsonl`；本修正案写于 6 轮 INVALID
  （无有效结果、无泄漏率数字）之后，早于 `/draft` 的第一次真实使用。
- 作用域：**只改产品放行**，不动考试——`nh gate`、225 格、裁决表、统计阈值
  全部原样；考试用的 `PROTOCOL_VERSION` 仍停在修正案 1/2/3/4/5/6。

## 为什么改

六轮 kill-gate 全死于模型长度控制（仪器校准问题），有效结果迟迟出不来；维护者决定
**先让作者用上起草，边用边校准**。这是一条**产品放行**决定，不是科学结论：
「图谱约束是否真的有效」在有效裁决之前不对外声称。

## 裁定

1. 公开 `POST /api/projects/{pid}/chapters/{n}/draft` **不再返回 501**，改为真实起草
   接口；响应与前端 UI **必须带「实验状态」标注**（未经 kill-gate 裁决）。
2. ADR 0010 D6 的「公开 `/draft` 在 M2 PASS 与 ADR 0009 完成前仍返回 501」
   就此修改为「可先行开放，但必须带实验标注」；ADR 0010 的 D1–D5（Writer 边界）
   不变。
3. 长度按 [ADR 0013](adr/0013-draft-length-is-a-request-parameter.md)：
   作者随请求传 `LengthSpec`，后端只验硬上限（中文 20,000 / 英文 12,000）。
4. kill-gate 本身不变：`nh gate` 仍是唯一判分仪器，ADR 0009 仍等一轮有效 run，
   「图谱约束有效」的科学主张在有效裁决之前不写进任何对外材料。

## 诚实声明

放行 ≠ 验证通过。作者现在用到的起草是**未经考试的能力**；如果将来 kill-gate 判负
（图谱约束无效），本修正案会被撤销、起草线会被砍，而已产生的使用记录就是那次裁决
的证据之一。协议冻结正文逐字未动；本修正案另开文件，撤销时同样需要一次显式 commit。
