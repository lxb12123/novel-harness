2026-09-05，维护者裁定**砍掉最后一条系统规则 R3 `DEAD_SPEAKS`**（见
[ADR 0042](adr/0042-dead-speaks-cut.md)）。`SYSTEM_RULES` 因此是空的。

> 「引擎自带的连续性规则，能不能**在真书上少误报、在合成小册子上多真阳性**」——

四条规则先后走完：R5（2026-08-02，ADR 0014）、R4（2026-08-14，ADR 0027）、
R2（2026-08-27，ADR 0040 + 修正案 1，题数 25 → 10）、**R3（今天）**。
**主语没了，不是「这门考试变难了」，是它的题目不存在了。**

## 那次「双边门槛已过」还算数吗

**算，作为历史事实**：2026-08-03 那次通过是对着当时的规则集量的，结论是「当时那套规则
在合成小册子上打得准」。它没有被推翻，只是**它测的那套规则今天不在产品里了**。

⚠️ 别拿它替今天的任何东西背书——尤其别拿它说「本引擎的连续性检查已验证」。

`forbidden_literal`（精确子串匹配，**结构上不可能误报**：命中即逐字出现）。
