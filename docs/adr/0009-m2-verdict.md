# ADR 0009：M2 kill-gate 的裁决（维护者裁定，非数据裁决）

- 状态：已接受
- 日期：2026-08-03
- 性质：**维护者裁定**（[修正案 9](../EVAL_PROTOCOL_AMENDMENT_9.md)），
  不是数据裁决——写明白这一点是本 ADR 存在的意义。

## 裁决

**M2 通过。** 依据（修正案 9 原文）：

1. 仪器校准完成：第八轮 44 格 0 INVALID；第九轮进行中 0 INVALID；
2. 修正案 8 长度降权后，长度不再系统性判死；
3. 起草功能已实验开放多日，维护者判断可用性达标。

## 证据链状态（必须如实读）

- 三臂泄漏率、Δ、McNemar p 值、符号稳定：**尚未产出**。
- 「图谱约束有效」的科学主张：**未证明**，不得写进任何对外材料。
- `nh gate` 保留为可跑仪器；第九轮跑完的结果作为补充证据，
  可触发再评估，不推翻本裁定。
  （**2026-08-20 补记**：命令行面整个删了，[ADR 0034](0034-no-command-line-surface.md)。
  上面那句原文一字不动——**仪器保留这条正是它被保下来的理由**；今天的入口是
  `python -m novel_harness.gate`，逻辑同一份，`runs/` 落点同一处。）
- 将来若补跑出有效轮，数据可把本裁决升级回「数据裁决」。

## 为什么记录而不是不记录

协议 §8 说 ADR 0009「跑完写」——那是预注册对**数据裁决**的时序要求。
维护者裁定可以改变这个时序，但必须显式记下「改的是时序、换的是证据类型」，
否则后人会把一份没有数据的「通过」读成有数据的通过。
