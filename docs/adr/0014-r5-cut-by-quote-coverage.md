# ADR 0014：R5 判据改为引语口径，实测 8.2% → 砍掉 R5

- 状态：已接受
- 日期：2026-08-02
- 解决的问题：ADR 0005 的 R5 判据分母（称呼词实例）和探针实测分母（引语条数）
  不是一回事。按 ADR 0005 自己的规矩：**先统一口径，再填「实测结果」**。

## 判据改为引语口径

`ADDRESS_CONFLICT` 的退路是「只在显式说话人标签内开火」——所以它该问的问题是
**「显式标签覆盖了多少句对白」**，不是「称呼实例里有多少落在标签位置」。引语是
对话的单位；覆盖率 = 带显式标签的引语 / 全部引语，直接回答规则可用性。

称呼实例口径需要先建花名册 + gold 才能数分母，而它回答的是「名字识别」不是
「规则能不能开火」，对 R5 的生死是间接的。探针脚本自 2026-07-16 起量的就是
引语口径——判据跟着可执行副本走（同 ADR 0005 自己那条「以脚本为准」的纪律）。

## 实测结果（2026-08-02）

- 样本：`/Users/lixibin/Desktop/187817.txt`（红楼梦同人，158 章，取前 3 章）
- 三章引语：30 / 35 / 32 条；带显式说话人标签：2 / 1 / 5 条
- **合计 8 / 97 = 8.2% < 10%** → 按 ADR 0005 判据 **R5 当场砍掉**
- M3 验收标准相应改写：规则集 = **R2 / R3 / R4**，不再含 R5

## 若决策错误，修复成本

低：R5 从未实现，砍 = 少做一条。将来若出现显式标签覆盖率高的书或明确需求，
凭实测数据重新评估（本 ADR 就是那个触发条件的记录点）。
